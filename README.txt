ALEF MARKET CENTER
===================

Files:
- index.html
- style.css
- script.js

How to run:
1. Put all three files in the same folder.
2. Open index.html in Chrome/Edge.
3. Internet is required for Google Fonts and the sample product images.

Telegram:
- Owner username: @YabuFkir
- Product order buttons open Telegram with an order message containing product name, price and quantity.

IMPORTANT BOT NOTE:
This frontend can open the Telegram owner chat. A true Telegram Bot API integration, where the website sends an order directly to AlefMarketCeneterBot, requires a backend/server and the bot token. Never place the bot token in JavaScript or HTML.

To use your own product images:
Replace each image URL in script.js with:
images/your-image.jpg

To use your own logo:
Add images/logo.png and replace the brand-logo section in index.html if desired.
